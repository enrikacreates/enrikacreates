# Poster prompts, round four

Four subjects. These are the only thing standing between these projects and the
grid: all four have their Sanity entry written and published, and the grid shows
a project only once it has a poster.

Paste each subject into the prompt you used for the last nine. Save the result
as `public/assets/posters/<slug>.png` and tell me the slug, or run:

```
npm run poster -- --slug <slug> --subject "<subject>" --color "<hex>"
```

Nothing else is needed. The colour below is a suggestion, not a requirement: it
is the project's existing card colour, and whatever the poster's background
actually comes out as gets measured and used as its page colour.
